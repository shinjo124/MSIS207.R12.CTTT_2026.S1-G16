# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Travelers discovering destinations and planning trips together, primarily on mobile devices.

## Product Purpose

Combine a travel community with shared trip planning, budgeting, and an interactive calendar.

## Capabilities and Constraints

The dashboard surfaces current or upcoming trips, events, budgets, weather, and sourced travel news. Trip members with permission can collaborate in real time. Trip times use the destination time zone. Existing accounts and data should be preserved. Offline users can view trip data already loaded in the current session but need a connection to save.

## Product Principles

- Make the next action clear across the application.
- Favor mobile use while supporting desktop workflows.
- Present real data and attribute external information.
- Keep shared planning responsive and understandable.
